# StudentHub — Student Management System

A beginner-friendly frontend mini-project built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Add a student with name, email, course, and marks
- Search records by name, email, or course
- Automatically show pass/fail status (40 marks is the demo pass mark)
- Show total students, passed students, and average marks
- Delete student records
- Save records in browser `localStorage`
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a modern browser.
3. Add, search, or delete records to test it.

No installation, build tools, or API keys are required.

## Technologies
- **HTML** — page structure and form
- **CSS** — layout, colors, responsive styling
- **JavaScript** — form handling, search, calculations, delete action
- **localStorage** — saves data in the same browser

## Important limitation
This is a **frontend demonstration**, not a production student database. Records are saved only in the browser where the app is opened. It has no login system, server, or shared database.

## Demo steps
1. Show the dashboard totals.
2. Add a student with marks such as 85.
3. Search for the student's name.
4. Explain the automatically calculated result and average.
5. Delete the demo student.
